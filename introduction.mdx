AETHON is a fully static, Spanish-language online bookstore front-end built with Bootstrap 5. It targets developers and students who want a ready-to-run e-commerce UI they can open directly in a browser — no build tools, no backend, and no package manager required. This documentation covers every page and component in the project, from cloning the repository to customizing the catalog filters.

The site ships with a full dark theme (black `#000000` body, `#1a1a1a` cards) styled through a modular set of CSS files, a reusable navbar/carousel/footer loaded via `fetch()`, and a catalog page with genre, tag, price, and author filters. Book categories include novels, science, university textbooks, children's books, architecture, technology, and more — all presented in a Spanish-language interface.
