The carousel is the first thing visitors see on the AETHON homepage. It showcases three featured books with a full-width cover image and a caption overlay, and automatically advances every two seconds. Like the navbar and footer, the markup lives in a standalone `carousel.html` file that pages load at runtime via `fetch`.

## HTML structure

The full source of `carousel.html` is shown below. It uses Bootstrap's carousel component with three slides and navigation controls.

## Adding a new slide

<Steps>
  <Step title="Add a slide indicator button">
    Inside the `.carousel-indicators` div, append a new `<button>` with the next `data-bs-slide-to` index (for a fourth slide, use `3`):

    ```html
    <button type="button" data-bs-target="#carouselExampleCaptions" data-bs-slide-to="3"
        aria-label="Slide 4"></button>
    ```
  </Step>
  <Step title="Add the slide item">
    Inside `.carousel-inner`, append a new `.carousel-item` div with your book's cover image and caption:

    ```html
    <div class="carousel-item">
        <img src="img/your-book-cover.png" class="d-block w-100" alt="Slide 4">
        <div class="carousel-caption d-none d-md-block">
            <h5 class="fw-bold" style="color: black;">Your Book Title</h5>
            <p style="color: #d0d0d0;">A short description of the book.</p>
        </div>
    </div>
    ```
  </Step>
  <Step title="Place the cover image in img/">
    Save your book's cover image in the `img/` directory. The carousel sizes images to the 1920 × 800 aspect ratio defined in `.carousel-inner`; use a landscape-oriented cover for the best result.
  </Step>
</Steps>

<Note>
Only one `.carousel-item` should carry the `active` class. That class marks the initially visible slide. Do not add `active` to your new item unless you want it to appear first.
</Note>

## Bootstrap Carousel initialization

After the carousel HTML is injected into the page, `js/script.js` initializes it with a 2-second interval and touch-swipe disabled:

```javascript js/script.js
const myCarouselElement = document.querySelector('#carouselExampleCaptions');
const carousel = new bootstrap.Carousel(myCarouselElement, {
    interval: 2000,
    touch: false
});
```

| Option | Value | Effect |
|---|---|---|
| `interval` | `2000` | Advances to the next slide every 2 000 ms |
| `touch` | `false` | Disables swipe gestures on touch devices |

## Loading the carousel dynamically

Add the placeholder `<div>` in your page's `<body>`:

```html
<div id="carousel-placeholder"></div>
```

Then call `loadComponent` in the `DOMContentLoaded` listener:

```javascript
document.addEventListener('DOMContentLoaded', function() {
    loadComponent('carousel.html', 'carousel-placeholder');
});
```

Link the carousel stylesheet in the `<head>`:

```html
<link href="css/carousel.css" rel="stylesheet">
```

<Tip>
The carousel is designed for the homepage only. Pages such as `ranking.html` and `filtros.html` do not include `carousel-placeholder` or the `carousel.css` link.
</Tip>
