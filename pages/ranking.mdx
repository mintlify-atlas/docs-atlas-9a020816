The AETHON ranking page (`ranking.html`) displays the most popular books across three dimensions — most visited, most sold, and highest rated. All data is embedded directly in the page and rendered client-side without any network requests.

## Page structure

The ranking page has a single `.ranking-section` that contains:

1. A page heading ("Ranking de Libros")
2. A **nav row** with three tab buttons and a time-period filter dropdown
3. Three **tab panels**, one for each ranking dimension

## Tab panels

Clicking a tab button shows the corresponding panel and hides the other two. The active panel's `<div>` carries the class `ranking-panel active`.

## Time-period filter

The dropdown next to the tabs lets you select the time window for the ranking. The selected period is stored per-tab so switching tabs restores the previously chosen filter for that tab.

Available options:

- Diario *(default)*
- Semanal
- Mensual
- Anual
- Todo el tiempo

<Note>
The time-period filter only updates the dropdown label and highlights the active option visually. The underlying `booksData` arrays are static and do not change based on the selected period. Connecting the filter to real time-windowed data requires a backend API or separate data sets per period.
</Note>

## JavaScript functions

### `renderAllGrids()`

Called once on `DOMContentLoaded`. Iterates over all three tab keys, finds the corresponding `#grid-{tab}` element, and fills it with `bookCard()` HTML for every entry in that tab's data array.

```javascript
function renderAllGrids() {
    ['visitados', 'vendidos', 'valorados'].forEach(function (tab) {
        var grid = document.getElementById('grid-' + tab);
        if (!grid) return;
        grid.innerHTML = booksData[tab].map(function (book, i) {
            return bookCard(book, i + 1);
        }).join('');
    });
}
```

### `initTabs()`

Attaches `click` listeners to each `.ranking-tab-btn`. On click it removes `active` from all tabs and panels, adds it to the clicked tab and its matching panel, and restores the time-filter label for that tab.

```javascript
function initTabs() {
    var tabs = document.querySelectorAll('.ranking-tab-btn');
    tabs.forEach(function (btn) {
        btn.addEventListener('click', function () {
            tabs.forEach(function (t) {
                t.classList.remove('active');
                t.setAttribute('aria-selected', 'false');
            });
            this.classList.add('active');
            this.setAttribute('aria-selected', 'true');

            document.querySelectorAll('.ranking-panel').forEach(function (p) {
                p.classList.remove('active');
            });
            activeTab = this.dataset.tab;
            document.getElementById('panel-' + activeTab).classList.add('active');

            document.getElementById('filter-label').textContent = tabFilters[activeTab];
            updateFilterHighlight();
        });
    });
}
```

### `initFilter()`

Attaches `click` listeners to each `.ranking-filter-item` in the dropdown. Selecting an item stores the value in `tabFilters[activeTab]`, updates the visible label, and closes the Bootstrap dropdown.

```javascript
function initFilter() {
    var items = document.querySelectorAll('.ranking-filter-item');
    items.forEach(function (item) {
        item.addEventListener('click', function (e) {
            e.preventDefault();
            var value = this.dataset.value;
            tabFilters[activeTab] = value;
            document.getElementById('filter-label').textContent = value;
            updateFilterHighlight();
            var dropdownEl = document.getElementById('rankingFilterBtn');
            var dropdown = bootstrap.Dropdown.getInstance(dropdownEl);
            if (dropdown) dropdown.hide();
        });
    });
}
```

<Tip>
To add a fourth ranking dimension (e.g., "Mejor precio"), add a new key to `booksData`, a new tab button with `data-tab="nuevotab"`, a new panel `<div id="panel-nuevotab" class="ranking-panel">`, and an initial entry in `tabFilters`.
</Tip>
