The AETHON homepage is the primary entry point for the bookstore. It combines a full-width hero carousel with curated book sections to surface featured content and drive users toward individual book detail pages.

## Page layout

The homepage (`index.html`) is divided into four main areas:

1. **Hero carousel** — a Bootstrap 5 auto-playing slideshow injected from `carousel.html`
2. **Novela Destacada** — a large, full-width featured book block
3. **Libros Destacados** — a four-book grid of top-ranked titles
4. **Secondary featured book** — a second wide-format book highlight

The navbar and footer are also injected dynamically at runtime.

The carousel lives in its own partial file (`carousel.html`) and is injected into `#carousel-placeholder` on page load. It contains three slides, each with a cover image and a caption overlay:

## Component-loading pattern

AETHON uses a fetch-based partial HTML injection pattern throughout the project. A single `loadComponent()` helper function fetches an external HTML file and inserts its content into a target element by ID. This keeps the navbar, carousel, and footer in dedicated files that can be reused across pages without duplication.

```html
<!-- index.html — placeholder divs injected at runtime -->
<div id="navbar-placeholder"></div>
<div id="carousel-placeholder"></div>
<!-- ... page content ... -->
<div id="footer-placeholder"></div>

<script>
  // Fetch a partial HTML file and inject it into a DOM element
  function loadComponent(url, elementId) {
    fetch(url)
      .then(response => response.text())
      .then(data => {
        document.getElementById(elementId).innerHTML = data;
      })
      .catch(error => console.error('Error cargando ' + url + ':', error));
  }

  document.addEventListener('DOMContentLoaded', function () {
    loadComponent('navbar.html',   'navbar-placeholder');
    loadComponent('carousel.html', 'carousel-placeholder');
    loadComponent('footer.html',   'footer-placeholder');
  });
</script>
```

<Note>
Because `loadComponent()` uses `fetch()`, the page must be served over HTTP or HTTPS. Opening `index.html` directly as a `file://` URL will cause CORS errors and the navbar, carousel, and footer will not render.
</Note>

Every page in the AETHON project follows this same pattern. The `carousel.html` partial is loaded only on the homepage (`index.html`); all other pages inject only the navbar and footer.
