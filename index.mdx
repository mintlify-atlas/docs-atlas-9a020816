AETHON is a fully-featured bookstore frontend built with plain HTML, CSS, and Bootstrap 5. It delivers a sleek dark-themed shopping experience with a filterable book catalog, real-time rankings, detailed book pages with comments and reactions, and user login and registration flows — all without a backend dependency.

## Quick start

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/SuarezCaceres/AETHON-ecomerce.git
    cd AETHON-ecomerce
    ```
  </Step>
  <Step title="Open the site">
    Open `index.html` in your browser directly, or serve it with any static file server:
    ```bash
    npx serve .
    ```
  </Step>
  <Step title="Explore the pages">
    Navigate through the homepage, catalog (`filtros.html`), rankings (`ranking.html`), and a book detail (`book.html`) to see the full experience.
  </Step>
  <Step title="Customize">
    Edit `css/styles.css` to adjust colors and layout, then update `js/filtros.js` to add your own book data.
  </Step>
</Steps>

<Note>
  AETHON is a static frontend — no server or database is required. All data is defined directly in JavaScript files.
</Note>
