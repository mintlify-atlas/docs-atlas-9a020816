The footer appears at the bottom of every page in AETHON and provides brand information, quick links to book categories, and contact details. Like the navbar, the markup lives in `footer.html` and is injected at runtime using `fetch`, so a single edit propagates to all pages instantly.

## HTML structure

## Column breakdown

The footer body uses a CSS grid (`grid-template-columns: 1.5fr 1fr 1fr`) to lay out three columns side by side on desktop. On screens narrower than 900 px the brand column spans the full width, and below 576 px all three columns stack vertically.

### Brand column

The first column carries the **El Amazonas** brand name, a short description, and three circular social-link buttons (Facebook, Twitter/X, Instagram). The buttons are placeholder `#` hrefs — replace them with real profile URLs when the accounts are live.

### Book categories column

The second column lists six book categories as links under the heading **Tipos de Libros**:

- Libros universitarios
- Libros escolares
- Libros infantiles
- Arquitectura y diseño
- Literatura e Idioma
- Tecnología y Ciencia

Each `<a href="#">` is a placeholder. Wire these to filtered catalog pages once the category routes exist.

### Contact column

The third column shows three items, each with a red SVG icon and a text label:

| Icon | Detail |
|---|---|
| Location pin | Av. Amazonas 1234, Lima, Perú |
| Clock | Lun–Vie: 9am – 6pm |
| Lock | Pago 100% seguro |

## Loading the footer dynamically

Add the placeholder `<div>` near the end of your page's `<body>`, after the main content:

```html
<div id="footer-placeholder"></div>
```

Then call `loadComponent` inside the `DOMContentLoaded` listener:

```javascript
document.addEventListener('DOMContentLoaded', function() {
    loadComponent('footer.html', 'footer-placeholder');
});
```

Link the footer stylesheet in the `<head>`:

```html
<link href="css/footer.css" rel="stylesheet">
```

## Updating footer content

<Steps>
  <Step title="Update the brand name">
    Open `footer.html` and change the text inside `<h3 class="footer-brand-title">`. The current value is `El Amazonas`.

    ```html
    <h3 class="footer-brand-title">Your Brand Name</h3>
    ```
  </Step>
  <Step title="Update social links">
    Replace the `href="#"` on each `.footer-social-btn` anchor with the real URL for each platform:

    ```html
    <a href="https://facebook.com/yourpage" class="footer-social-btn" aria-label="Facebook">f</a>
    <a href="https://x.com/yourhandle" class="footer-social-btn footer-social-x" aria-label="Twitter / X">𝕏</a>
    <a href="https://instagram.com/yourprofile" class="footer-social-btn" aria-label="Instagram">in</a>
    ```
  </Step>
  <Step title="Update contact info">
    Edit the three `<span>` text nodes in the `.footer-contact-list` to reflect your actual address, hours, and payment messaging:

    ```html
    <span>Your Street Address, City, Country</span>
    <span>Mon–Fri: 10am – 7pm</span>
    <span>Secure checkout guaranteed</span>
    ```
  </Step>
</Steps>
